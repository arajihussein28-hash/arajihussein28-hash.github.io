# REPLACE YOUR OLD SITE ON GITHUB

Keep your existing repository:

`arajihussein28-hash.github.io`

You do NOT need to delete the repository.

For the first V2 install, upload these files to the repository root:
- index.html
- style.css
- script.js
- site-data.js
- assets/projects/README.txt

Files with the same names replace the old versions when committed.

Your URL stays:
`https://arajihussein28-hash.github.io`

After that, read `HOW_TO_UPDATE.md`.
