# V3 — Easy updates

For most changes, edit only `site-data.js`.

- Add/remove project: edit the `projects` array.
- Add screenshot: put it in `assets/projects/`, then set the project `image` path.
- Add LinkedIn: set `linkedin` in `site-data.js`.
- Change skills/experience/about: edit `site-data.js`.
- Change design: edit `style.css`.
- Replace resume: upload a new `resume.pdf` with the same name.
