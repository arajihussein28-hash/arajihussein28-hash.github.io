# Hussein Araji — Personal Portfolio

My personal website where I share what I’m learning, the projects I’ve worked on, and my experience as a Computer Science student at Carleton University focusing on AI and Machine Learning.

I wanted the website to have some personality, so I went with a dark red theme, pixel fonts, a Pac-Man name animation, and a tiny character that jumps above the navigation links.

## What’s on the site

- A bit about me and my interests
- Projects, including QueueUp, a team-built Django gaming lobby platform
- My skills and the tools I’m learning
- Education and work experience
- My resume and contact links

## Built with

HTML, CSS, and JavaScript. No framework or build step.

## How the files are organized

- `index.html` — page structure
- `style.css` — layout, colours, fonts, and animations
- `script.js` — navigation, project popups, and interactive features
- `site-data.js` — project details, skills, experience, and contact information
- `resume.pdf` — my resume

## Running it locally

Download the files and open `index.html` in a browser. Keep the files together so the styles and scripts load properly.

## Still working on it

This portfolio will change as I learn more and build new projects. Right now, I’m working on keeping the code organized and making the site look good on different screen sizes.
